The top-level help is the map: secondbrain --help lists exactly these three, and --help is the only option anywhere in the tool. Everything else is configured through the environment — which is the next section.

Three environment variables

the knobs on the back.

Copy .env.example to .env, then load it explicitly with uv run --env-file .env secondbrain … — it is never auto-loaded, so nothing changes behind your back.

SECONDBRAIN_DIR default · ~/secondbrain/

Where your notes live. Read fresh on every call, so pointing it somewhere else works per-command.

LOG_LEVEL default · INFO

How chatty the console is. Set DEBUG to watch it choose directories and count files.

LOG_FILE default · app.log in your notes dir

Always records at DEBUG, rotates at 50 KB, keeps one old copy. If it can’t be opened, the command still runs.

Every log line looks like this — one compact pipe-delimited row, with the level squeezed down to a single letter (T · D · I · S · W · E · C): 
2026-08-02 09:14:07 | I | secondbrain.cli:new:25 | Created note: /home/you/secondbrain/2026-08-02-cafe-ideas-for-monday.md
